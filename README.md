# Financial Accounting System 🪙
Простое консольное приложение на Java для ведения финансового учета. Программа позволяет пользователю управлять записями о доходах и расходах, используя возможности обработки строк и дат.
# 🚀 Особенности
Учет операций: Возможность добавлять и просматривать финансовые транзакции.
Работа с датами: Использование современных API Java для фиксации времени операций.
Консольный интерфейс: Удобное текстовое меню для взаимодействия с пользователем.
Чистая архитектура: Разделение логики (сервисы), данных и интерфейса (UI).
# 🛠 Технологии
Language: Java 11+
Concepts: OOP, String processing, Java Time API (LocalDate, LocalDateTime).
# 📂 Структура проекта
Проект организован по пакетам для обеспечения модульности:
strings_and_dates — точка входа в приложение (класс Main).
strings_and_dates.service — бизнес-логика (обработка данных, расчеты).
strings_and_dates.ui — пользовательский интерфейс и взаимодействие через консоль.
strings_and_dates.model — (опционально) классы данных, такие как Transaction.
